# AI-Powered Medical Diagnosis System

An intelligent system that predicts possible diseases based on user symptoms using Machine Learning. Built as part of the **AICTE-Microsoft-SAP TechSaksham Internship**.

## Features
- Symptom-based Disease Prediction
- Confidence Scores & Top 3 Conditions
- Descriptions, Precautions, and Treatments
- Patient Info Form
- PDF Report Generation
- Fully Offline - No Internet/API required

## Tech Stack
- Python
- Streamlit (Frontend)
- Scikit-learn (ML Model)
- FPDF (PDF export)
- Pandas & NumPy (Data handling)
